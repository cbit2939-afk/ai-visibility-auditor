      How TinyFish is used

      Search measures live query visibility, ranking position and snippet context.

      Fetch extracts the live page as an AI text tool sees it: metadata, headings, content, links and images.

      Agent opens the live page in a browser workflow to detect rendered content and interaction/JavaScript gaps that plain extraction can miss.

      Bounty requirement checklist

      3 endpoints
      ✓ Takes any public URL + optional target query
      ✓ TinyFish Search and Fetch both contribute meaningfully
      ✓ Reports what AI can/can't read + concrete fixes
      ✓ Quick demo targets for several real pages
      ✓ Explains exactly how TinyFish is used
      ✓ Audits live pages, not saved copies

      Scope: this is an AI-readability/search-visibility audit. It does not claim Lighthouse, Core Web Vitals, Search Console, backlinks, traffic or indexation data.
