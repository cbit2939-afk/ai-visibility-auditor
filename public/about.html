How it works

Built on the official TinyFish Fetch API.

This community bounty build sends a single target URL to TinyFish Fetch with HTML, links and image extraction enabled. The returned structured page data is scored with deterministic on-page SEO rules.

What it checks

Title and description presence/length, heading hierarchy, visible content depth, internal/external links, image alt coverage where detectable, page language, HTTPS and basic long-form structure.

What it does not claim

This is not Google Lighthouse and does not report Core Web Vitals, indexation status, backlinks or Search Console data. Its score is an explainable on-page checklist score.

API key handling

The key is submitted only with the current audit request and forwarded to TinyFish as the official X-API-Key header. The app has no database and does not persist keys.
